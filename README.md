## 🔥 核心项目展示

### 1. 制造业 AI 数字员工 (03_制造业数字员工)
*   **项目背景**：解决传统制造企业人工手动修改产线数据低效、易错的痛点。
*   **核心亮点**：
    *   **自然语言驱动**：用户输入“查A线数据，低于80%改预警”，AI自主完成查数据、算指标、改状态全闭环。
    *   **抗干扰模糊推理**：即使输入“a生产xian”这类拼音+错别字，系统也能精准定位至“A生产线”。
    *   **极致异常兜底（防幻觉）**：面对极其脏的工厂数据（汉字、负数、除零异常），系统成功拦截“55022%”这种物理不可能的数据，阻止 AI 产生灾难性误导建议。
    *   **多轮记忆与主动澄清**：引入 Memory 机制，且当识别到模糊指令（如“那个线”）时，会主动反问用户，而非盲目执行。
*   **技术栈**：Python / LangChain / DeepSeek API / Pandas / Streamlit

### 2. 工程合同智能问答系统 (02_RAG智能问答应用)
*   **核心亮点**：将长篇工程合同PDF切分存入向量库，实现基于语义检索的精准问答，解决大模型“幻觉”问题。
*   **技术栈**：LangChain / ChromaDB / HuggingFace Embeddings / Streamlit
